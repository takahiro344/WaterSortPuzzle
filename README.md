# Water Sort Puzzle Solver（不明色1個まで推測対応）

[baclips.com の Water Sort Puzzle 解答アプリ](https://baclips.com/solve-water-sort-puzzle/) の
UI・操作フローをベースに、TypeScript + React で再実装した非公式版です。

オリジナル版は「すべての色が判別できる画像」であることが前提でしたが、本アプリでは
**グリッド上の1マスだけ「不明」に指定しても解ける**よう拡張しています。
（色数と各色の本数（通常は1色あたり4段）が既知であれば、他の色の出現数から
消去法で不明な1マスの色を一意に確定できる、という考え方に基づいています。）

## 使い方

1. **(1/3) 画像選択**: Water Sort Puzzle を1手も動かす前のスクリーンショット（または
   その写真）を選択します。
2. **(2/3) グリッド調整**: 四隅のハンドルをドラッグし、各試験管の色の中心にグリッドの
   交点が来るように調整します。
   - `c-` / `c+`: 試験管の本数（列）を増減
   - `g-` / `g+`: 1本あたりの段数（行）を増減
   - 交点をクリック: `自動 → 空 → 不明 → 自動` の順に切り替え（不明は同時に1個まで）
   - 画像に写っていない空の試験管がある場合は「空の試験管の数」に入力
3. **[解く]** を押すと、色を自動クラスタリング（かつ不明マスがあれば推測）した上で
   最短手順を探索します。
4. **(3/3) 解答**: `+` / `-` ボタンで手順を1手ずつ確認できます。

画像処理・パズルの求解はすべてブラウザ内（クライアントサイド）で行われ、
画像やパズルの内容がサーバーに送信されることはありません。

## 技術構成

- TypeScript + React（Vite）
- 色取得: `<canvas>` 上でグリッド交点付近のピクセルを平均し、色距離でクラスタリング
- 不明色推測: `src/colorLogic.ts` の `inferUnknownColor`
  - 各色の出現数をカウントし、「あと1個で規定数（段数）に達する色」が1色だけあれば
    それを不明マスの色として採用
  - 該当する色が無ければ、未検出の新しい色として補完
  - 複数の色が該当する場合は一意に決定できないためエラーを表示
- パズル求解: `src/solver.ts`
  - 状態空間を優先度付きキュー（ベストファースト探索）で探索
  - 「分割注ぎ」は不可（移動元の同色連続分がすべて移動先に収まる場合のみ移動可）という
    オリジナル版と同じルールを採用

## ローカルでの動作確認

### Docker（推奨）

```bash
docker compose up --build
```

起動後、ブラウザで `http://localhost:8080` を開いてください。

停止するには:

```bash
docker compose down
```

### Docker を使わない場合

```bash
npm install
npm run dev
```

`http://localhost:5173` を開いてください。

## ディレクトリ構成

```
src/
  types.ts           型定義（色ID、EMPTY/UNKNOWN/AUTOなど）
  priorityQueue.ts    探索用の優先度付きキュー
  solver.ts           パズル求解ロジック
  colorLogic.ts        色クラスタリング＆不明色推測ロジック
  paletteDisplay.ts    色ID→表示色の変換
  components/
    ImageUpload.tsx    画像選択（(1/3)）
    GridEditor.tsx      グリッド調整・色取得（(2/3)）
    SolutionViewer.tsx  解答ステップ表示（(3/3)）
  App.tsx              画面遷移の管理
  main.tsx             エントリポイント
Dockerfile             マルチステージビルド（Vite build → nginx配信）
docker-compose.yml
nginx.conf
```

## 制限事項

- 不明マスは同時に1個までです（2個以上不明な場合は一意に決定できません）。
- 移動ルールは「分割注ぎ不可」（オリジナル版 v.2026-04-09 と同様）を前提としています。
- 1色あたりの段数（試験管容量）はグリッドの行数と一致させてください（既定4）。
